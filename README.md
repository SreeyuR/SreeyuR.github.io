# sreeyur.github.io

Personal website of **Sreeyutha Ratala**: Software Engineer at Google and 2026 Caltech CS grad, passionate about building impactful AI applications and doing ML research.

**Live at [sreeyur.github.io](https://sreeyur.github.io)**

## What's inside

- **About**: who I am, what I work on, and how to reach me
- **Leadership**: Camp Venom (a free coding camp I founded and still run), teaching at Caltech, and the Google Student Ambassador program
- **Projects & Publications**: my research and projects, with papers, posters, and slides that open right on the site
- **Fun**: two playable games and a travel gallery
  - *Return of the Imposter*: a platformer my friends and I wrote in C on a custom physics engine, compiled to WebAssembly so it runs in the browser
  - *Agent Academy*: a tiny reinforcement learning agent you can train, tease, and graduate, live in the browser

## Tech

Plain HTML, CSS, and JavaScript. No frameworks, no build step. Features a constellation background, light/dark mode, and a scraper-safe email. Hosted on GitHub Pages.
